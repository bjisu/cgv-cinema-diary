# 커서 첫 프롬프트 (아래 전체를 복사해서 커서 Agent 채팅에 붙여넣으세요)

---

이 폴더에서 CGV '시네마 다이어리' 프로토타입 개발을 시작한다.

먼저 `docs/PRD.md`와 `.cursorrules`를 정독하고, `design-reference/more-screen.png`(실제 CGV 앱 더보기 화면)를 확인해라. 이 두 문서가 모든 기능·디자인의 단일 기준이다.

지금부터 다음을 순서대로 진행해라:

1. 이 폴더에 Next.js 14+ (App Router) + TypeScript + Tailwind CSS 프로젝트를 생성해라. (기존 docs/, design-reference/, .cursorrules, README.md는 유지)
2. PRD §7의 디자인 토큰을 tailwind.config에 등록하고, Pretendard 폰트를 적용해라.
3. PRD §10의 폴더 구조대로 뼈대를 잡고, PRD §5의 데이터 모델·목데이터·Zustand persist 스토어를 구현해라.
4. 공통 레이아웃부터 구현해라: 최대폭 480px 모바일 컨테이너, 하단 탭바(홈·씨네톡·중앙 원형 빨간 '예매·예약' FAB·매점·더보기 — 아이콘과 라벨은 전부 검정), 앱 헤더.
5. **더보기 화면(`/more`)을 design-reference/more-screen.png와 1:1로 똑같이 재현해라.** 단 PRD §8 화면 01에 명시된 4가지 변경만 적용한다: '내가 본 영화' 자리를 '시네마 다이어리'(+NEW)로, 아바타에 미니 파코니 Lv 뱃지, 하단 AD 배너를 다이어리 프로모 배너로, 시네마 다이어리 탭 시 /diary 이동.
6. **이 더보기 화면이 앱의 첫 화면이다.** `/` 접속 시 스플래시·온보딩 없이 곧바로 더보기 화면이 뜨게 해라.
7. 개발 서버를 실행해서 여기까지 확인시켜줘.

이후 PRD의 나머지 화면(02~08, NFC)을 FR 번호 순서로 이어서 구현하되, 각 단계 완료 시 무엇을 만들었는지 한두 문장으로만 보고해라.

주의사항 (절대 규칙):
- Firebase 등 외부 백엔드 금지. 모든 데이터는 localStorage(Zustand persist).
- 디자인 창작 금지. PRD §7 토큰 외 임의 색상 금지. 기본은 흰 배경 + #121212 검정, 빨강 #FF2949는 포인트에만.
- 실제 영화 제목·포스터·실제 파코니 이미지 사용 금지. 가상 목데이터와 직접 제작한 SVG 에셋 사용.
- NFC와 영화표 OCR은 전부 시뮬레이션 연출로 구현(실패 케이스 없음) + 수동 입력·수정 폼 병행.
- 나는 비개발자다. 에러는 네가 스스로 고치고 결과만 짧게 한국어로 보고해라.
