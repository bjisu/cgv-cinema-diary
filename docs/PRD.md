## 1. 개요

### 1.1 제품 한 줄 정의
파코니 NFC 굿즈를 태그하면 CGV 앱 안의 '시네마 다이어리'로 진입하고, 영화표를 인증하면 관람 기록이 자동으로 쌓이며, 볼수록 파코니 캐릭터가 성장(레벨·칭호)하고 장르 취향 뱃지를 수집하는 기록·리텐션 서비스.

### 1.2 목적
- 굿즈가 '기록 도구'로 기능 → 실용성 상승, 콤보·특정관 연계 발매로 재구매 유도 (판매 촉진)
- 인증·기록·성장·뱃지가 모두 앱 전용 → 관람할 때마다 앱을 켜는 습관 형성 (앱 유입)
- 재관람 동기 강화, 관람 취향·빈도 데이터 확보, 앱 리텐션(MAU) 상승 (기대 효과)

### 1.3 이번 구현의 성격 (중요 — 개발 전 반드시 숙지)
이 프로젝트는 **실서비스가 아닌 고충실도(high-fidelity) 프로토타입**이다. 다음 원칙을 따른다.

1. **UI/UX는 실제 CGV 앱과 동일하게 재현한다.** 임의의 디자인 창작 금지. 색상·타이포·간격·컴포넌트 형태 모두 아래 §7 디자인 시스템을 따른다.
2. **백엔드 없음.** 회원가입/로그인 없음. 모든 데이터는 localStorage에 저장한다. Firebase, Supabase 등 외부 BaaS 절대 사용 금지.
3. **NFC 태그는 시뮬레이션.** 실제 NFC API를 쓰지 않고, 태그 연출 화면(버튼 + 애니메이션)으로 경험을 재현한다.
4. **영화표 OCR은 시뮬레이션 + 수동 입력 병행.** 이미지 업로드 시 "인식 중" 연출 후 목데이터가 자동 기입되고, 사용자가 직접 수정·입력할 수 있는 폼을 함께 제공한다.
5. 데모가 어떤 기기에서도 끊김 없이 작동하는 것이 최우선이다. 실패 케이스(인식 실패, 네트워크 오류 등)는 만들지 않는다.

### 1.4 범위
- **포함 (In Scope)**: 화면 8종 전체(§8) + NFC 태그 연출 화면 + CGV 앱 껍데기 UI(하단 탭바, 더보기 페이지, 헤더)
- **제외 (Out of Scope)**: 실제 예매/결제, 실제 로그인/CJ ONE 연동, 푸시 알림, 실제 씨네톡 커뮤니티(공유 화면은 목업으로 구현), 서버 API, 관리자 페이지

## 3. 사용자 및 시나리오

### 3.1 타깃 사용자
- 페르소나: 20~30대 CGV 관람객. 영화 관람 기록을 남기고 싶고, 캐릭터 굿즈(파코니)에 호감이 있으며, 수집·성장형 콘텐츠에 반응한다.

### 3.2 핵심 시나리오 (PPT 원안)
1. 매점 캐릭터굿즈에서 **파코니 NFC 굿즈 구매** (오프라인)
2. 굿즈 **태그 → CGV 앱 '시네마 다이어리' 딥링크 진입** (본 프로토타입에서는 태그 시뮬레이션 화면)
3. **영화표 인증**: 종이표 사진 촬영 / 모바일표 업로드 / CGV 예매내역 불러오기
4. **관람 정보 자동 기입**: 영화명·관람일시·상영관(좌석) 자동 기록
5. **파코니 레벨·칭호 상승**: 관람 편수 누적에 따라 성장
6. **장르 취향 뱃지 수집**: 장르별 관람 분석 → 뱃지 컬렉션 → 씨네톡 공유

## 4. 정보 구조 (IA) 및 CGV 앱 배치 전략

PPT의 UX 분석 결론: **신규 탭을 만들지 않는다.** 기존 CGV 앱 자산 위에 확장한다.

```
CGV 앱 (하단 탭바 — 실제 앱과 동일: 4탭 + 중앙 원형 '예매·예약' FAB)
├─ 홈              (목업: 정적 화면, 탭 전환만 가능)
├─ 씨네톡          (목업: 공유 게시물이 노출되는 피드 화면 — ⑧에서 사용)
├─ [예매·예약]     (중앙 빨간 원형 FAB — 목업: 정적 화면)
├─ 매점            (목업: 정적 화면, '파코니 NFC 굿즈' 카드 → NFC 안내)
└─ 더보기          (★ 핵심 진입점 — 실제 앱 스크린샷 그대로 재현, §8 화면 01)
    ├─ 프로필: 닉네임 님 · 내 등급 보러 가기 · 등급 진행바 · CJ ONE Point 카드
    ├─ 나의 정보 관리 (2열 텍스트 메뉴)
    │   ├─ 시네마 다이어리  ← ★ '내가 본 영화' 텍스트만 교체 (위치·스타일 동일)
    │   ├─ 보관함 / 스마트결제관리 / 예약·결제내역 / 내 차량번호 조회 / 자주가는 CGV
    └─ 하단 배너 영역 → 시네마 다이어리 프로모 배너로 활용
```

- **진입 동선 1 (메인)**: 더보기 → 나의 정보 관리 → **시네마 다이어리** (기존 '내가 본 영화' 자리)
- **진입 동선 2 (NFC)**: NFC 태그 시뮬레이션 (`/nfc` 경로 또는 첫 방문 스플래시의 "굿즈 태그하기" 버튼) → 태그 연출 → 시네마 다이어리 홈으로 딥링크
- **진입 동선 3 (공유)**: 씨네톡 탭에서 공유된 다이어리 게시물 확인

## 5. 데이터 모델 (localStorage)

Zustand persist 키: `cgv-cinema-diary`. TypeScript 타입 정의:

```ts
// 관람 기록 1건
interface DiaryEntry {
  id: string;              // uuid
  movieId: string;         // 목데이터 영화 참조
  title: string;           // 영화명
  posterUrl: string;       // 포스터 이미지 경로 (public/posters/*)
  watchedAt: string;       // ISO — 관람일시 (예: 2026-08-02T19:20)
  theater: string;         // 극장명 (예: 용산아이파크몰)
  screen: string;          // 상영관 (예: 5관)
  seat?: string;           // 좌석 (예: H12)
  genre: Genre;            // 대표 장르
  source: 'photo' | 'mobile' | 'booking' | 'manual';  // 인증 방식
  createdAt: string;
}

type Genre = '액션' | '드라마' | 'SF' | '코미디' | '로맨스' | '스릴러' | '애니메이션' | '공포';

// 사용자(단일, 로그인 없음)
interface UserState {
  nickname: string;        // 기본값 '파코니팬6671' (수정 가능) — 표기: "파코니팬6671 님"
  cjGrade: '일반';         // 목업 고정 (스크린샷 기준: 일반 · 0점 / 10,000점)
  points: number;          // 목업: 745 (CJ ONE Point, 스크린샷 기준)
  nfcTagged: boolean;      // NFC 태그(시뮬레이션) 완료 여부
  entries: DiaryEntry[];
  unlockedBadges: string[];    // 획득 뱃지 id 목록
  seenLevelUps: number[];      // 레벨업 연출을 이미 본 레벨 목록(중복 연출 방지)
}
```

### 5.1 파코니 레벨·칭호 규칙 (누적 관람 편수 기준)

| 레벨 | 필요 편수(누적) | 칭호 |
|---|---|---|
| Lv.1 | 1편 | 첫 관람 |
| Lv.2 | 3편 | 영화 새싹 |
| Lv.3 | 7편 | 극장 단골 |
| Lv.4 | 12편 | 시네필 |
| Lv.5 | 24편 | 시네마 마니아 |
| Lv.6 | 40편 | 파코니 마스터 |

- 레벨업 판정: 기록 저장 직후 편수 재계산 → 새 레벨 도달 && `seenLevelUps`에 없으면 ⑤ 레벨업 화면으로 이동.
- 파코니 캐릭터 이미지는 레벨별 6종 (public/paconi/lv1.png ~ lv6.png). 실제 파코니 에셋이 없으므로 **팝콘 캐릭터 일러스트를 SVG로 직접 제작**하되 레벨이 오를수록 커지고 장식이 추가되는 형태로 구현.

### 5.2 장르 뱃지 규칙

동일 장르 누적 편수 기준으로 획득. 각 장르당 1개 뱃지.

| 뱃지 | 조건 | 예시 이름 |
|---|---|---|
| 장르 입문 | 해당 장르 1편 | "액션 입문" |
| 장르 팬 | 해당 장르 3편 | "액션 팬" |
| 장르 마스터 | 해당 장르 7편 | "액션 마스터" |

- 뱃지 id 형식: `{genre}-{tier}` (예: `액션-fan`)
- 미획득 뱃지는 잠금(실루엣 + 자물쇠) 상태로 노출 → 수집 욕구 자극.

### 5.3 목데이터 (필수 포함)

- **영화 목데이터 12편 이상** (`data/movies.ts`): 제목·장르·포스터·러닝타임. 포스터는 저작권 문제가 없도록 CSS 그라데이션 + 타이틀 텍스트로 직접 제작한 가상 포스터 사용 (실제 영화 제목 사용 금지, 가상 제목: 예 "미드나잇 시티", "별의 저편" 등).
- **예매내역 목데이터 3건** (`data/bookings.ts`): '예매내역 불러오기' 시 노출.
- **씨네톡 피드 목데이터 5건** (`data/cinetalk.ts`): 다른 유저의 게시물처럼 보이는 피드.
- **초기 상태**: 최초 방문 시 entries에 시연용 기록 2건을 시드(seed)로 넣어 화면이 비어 보이지 않게 한다. (설정에서 "데이터 초기화" 제공)

## 7. 디자인 시스템 — "실제 CGV 앱과 동일하게" (최우선 요구사항)

> **원칙: 이 프로젝트에서 디자인 창작은 금지다.** 기준은 **첨부된 실제 CGV 앱 '더보기' 스크린샷**이며, 아래 컬러 값은 해당 스크린샷에서 직접 추출(picking)한 실측값이다. 개발 시 스크린샷 원본을 리포지토리 `design-reference/more-screen.png`로 저장해 두고, 모든 신규 화면은 이 화면과 나란히 놓았을 때 같은 앱으로 보여야 한다. 애매하면 항상 스크린샷을 기준으로 판단하고, 화려함보다 **정제된 상용 앱 품질**을 우선한다.

### 7.3 공통 컴포넌트 규격 (스크린샷 기준)

- **하단 탭바 (BottomTab)** — ★ 실제 앱 구조 그대로: 높이 약 64px + safe-area, 연회색빛 흰 배경(`#F7F7F7` 계열)에 상단 얇은 구분선.
  - 탭 4개 + 중앙 FAB: 홈(집 아이콘) · 씨네톡(말풍선/티켓 아이콘) · **[예매·예약]** · 매점(팝콘 아이콘) · 더보기(사람+줄 아이콘).
  - 중앙 FAB: 지름 약 72px 빨간 원(`cgv-red`), 탭바 위로 절반쯤 돌출, 흰색 Bold 13px 텍스트 "예매·예약" 2줄 중앙 정렬.
  - 아이콘·라벨은 활성/비활성 모두 **검정(`cgv-black`)** — 빨간 활성색을 쓰지 않는다(스크린샷 확인). 활성 탭은 라벨 Bold 처리. 아이콘은 검정 라인(스트로크 1.8px) 스타일.
- **헤더 (AppHeader)**: 높이 52px, 흰 배경, 좌측 뒤로가기(chevron-left 24px, `cgv-black`), 좌측 정렬 타이틀 H1(실제 앱은 좌상단 큰 제목 스타일) 또는 중앙 타이틀, 우측 아이콘 슬롯(티켓·종·검색 아이콘 재사용). 구분선 없이 흰 배경 연속(스크린샷 기준).
- **주요 버튼 (PrimaryButton)**: 높이 52px, `cgv-red` 배경, 흰 텍스트 16px Bold, radius 12px, 전체 폭. pressed 시 `cgv-red-deep`.
- **보조 버튼(아웃라인 pill)**: 스크린샷의 '자세히보기' 스타일 — 투명 배경 + 1px `cgv-black` 테두리, radius full(pill), 텍스트 13px `cgv-black`.
- **텍스트 메뉴 그리드 (TextMenuGrid)** — ★ 더보기 '나의 정보 관리' 스타일: 아이콘·chevron 없이 **굵은 검정 텍스트(17px Bold)만 2열 배치**, 행 간격 약 40px. 다이어리 내 설정성 메뉴에도 이 패턴 재사용.
- **카드 (GrayCard)**: `cgv-gray-100` 배경, radius 16px, **그림자 없음**(스크린샷 기준 플랫), 내부 패딩 20px. (CJ ONE Point 카드 스타일)
- **진행바 (GradeBar)**: 트랙 `cgv-bar-dark` 높이 24px radius full + 좌측 현재값 pill(그라데이션 `cgv-grad-start`→`cgv-grad-end`, 흰 Bold 텍스트). 트랙 아래 좌 '일반'(`cgv-gray-600`) / 우 '10,000점'(`cgv-gray-400`). 파코니 레벨 진행바는 이 컴포넌트를 그대로 재사용해 좌 pill에 "Lv.4", 우측에 "다음 레벨 24편" 표기.
- **바텀시트**: 상단 radius 20px, 핸들바 36×4px `#D9D9D9`, 배경 딤 `rgba(0,0,0,0.5)`.
- **NEW 뱃지**: `cgv-red` 텍스트 또는 배경 pill, 9px Bold "NEW" — 메뉴 텍스트 우측 상단에 소형 표기.
- **토스트**: 하단 탭바 위 72px, 검정 90% pill, 흰 텍스트 13px.
- 페이지 좌우 패딩 20px 통일(스크린샷 실측 비율). 섹션 간 간격 28~32px(실제 앱은 여백이 넉넉함). 터치 타깃 최소 44px.

### 7.4 인터랙션 톤
- 화면 전환: 좌→우 push (Framer Motion, 250ms ease-out)
- 바텀시트: 하단 slide-up 300ms
- 레벨업: 캐릭터 scale 1→1.15 bounce + confetti(카누스 라이브러리 canvas-confetti 허용) + 칭호 리본 fade-in

- 스캔 연출: 티켓 썸네일 위 레드 스캔라인 상하 왕복 2초 → 필드가 위→아래 순서로 타이핑되듯 자동 기입

## 8. 화면별 상세 명세 (총 8 + 3 화면)

라우팅 구조 (App Router):

```
/                     → ★ 첫 화면 = 더보기 화면(화면 01)으로 즉시 리다이렉트. 앱을 열면 무조건 더보기 화면이 먼저 보인다
/home /cinetalk /booking /store   → 목업 탭 화면
/more                 → 01 더보기 (★ 첫 화면이자 진입점 — 첨부 스크린샷 1:1 재현)
/nfc                  → NFC 태그 시뮬레이션 (FR-01)
/diary                → 02 시네마 다이어리 홈
/diary/verify         → 03 영화표 인증 (방법 선택 + 인증 진행)
/diary/verify/result  → 04 자동 기입 결과 (폼 확인·수정·저장)
/diary/levelup        → 05 파코니 레벨업 연출
/diary/badges         → 06 장르 취향 뱃지
/diary/archive        → 07 다이어리 아카이브
/diary/share          → 08 씨네톡 공유
```

### 화면 01 — 더보기 (★ 앱의 첫 화면이자 진입점) `/more` — 첨부 스크린샷을 1:1로 재현

**앱을 열면 가장 먼저 보이는 화면이다** (`/` 접속 시 즉시 이 화면). 스플래시·온보딩 없음.

첨부된 실제 CGV 앱 '더보기' 화면을 **레이아웃·간격·컬러까지 그대로 재현**하되, 딱 한 곳만 바꾼다: **'내가 본 영화' → '시네마 다이어리'** (같은 위치, 같은 17px Bold 검정 텍스트 스타일, 우측 상단에 소형 `NEW` 레드 표기만 추가).

위에서부터 순서대로:

1. **상단 우측 아이콘 3개**: 티켓 · 종(알림) · 돋보기(검색) — 검정 라인 아이콘, 동작 없음(목업).
2. **프로필 영역**: 좌측 `행복한포뇨6671 님`(24px Bold — 본 프로젝트는 기본 닉네임 "파코니팬6671 님", 수정 가능) + 그 아래 `내 등급 보러 가기 >`(15px). 우측 회색 원형 아바타(72px, `cgv-gray-100` 배경 + 사람 실루엣). **아바타 우하단에 미니 파코니 뱃지(FR-12)를 겹쳐 파코니 Lv.N 표시** — 이 화면에서 유일하게 허용되는 추가 요소.
3. **등급 진행바(GradeBar)**: 다크 트랙 + 좌측 그라데이션 pill `0점`, 아래 좌 `일반` / 우 `10,000점`. (정적 목업)
4. **CJ ONE Point 카드(GrayCard)**: 상단 행 = CJ ONE 컬러 로고 + `CJ ONE Point` + 우측 `745P` Bold. 얇은 구분선 아래 4열: `쿠폰 2` / `관람/기프트콘 0` / `기간횟수권 0` / `기프트카드`(아이콘). 숫자 22px Bold, 라벨 14px `cgv-gray-600`. (정적 목업)
5. **섹션 라벨** `나의 정보 관리` (15px, `cgv-gray-600`).
6. **TextMenuGrid 2열** (17px Bold, `cgv-black`, 행 간격 40px):
   - 1행: **시네마 다이어리** `NEW` | 보관함
   - 2행: 스마트결제관리 | 예약/결제내역
   - 3행: 내 차량번호 조회 | 자주가는 CGV
   - '시네마 다이어리'만 탭 시 `/diary` 이동. 나머지는 동작 없음(목업).
7. **하단 배너**: 스크린샷의 AD 배너 자리(연보라 `#E6DCFF`, radius 16px)를 **시네마 다이어리 프로모 배너**로 교체 — "영화표 찍고 파코니 키우자! 시네마 다이어리 오픈" + 파코니 일러스트 + 아웃라인 pill 버튼 `자세히보기` → `/diary`. 우상단 `AD` 대신 `NEW` 표기.
8. 하단 탭바: '더보기' 활성 상태.

- '실관람 등록' 연동(PPT ③안)은 이 화면에 별도 메뉴가 없으므로, `/diary/verify`의 방법 카드 설명에 "기존 실관람 등록과 연동" 문구로만 반영한다.

### 화면 NFC — 굿즈 태그 시뮬레이션 `/nfc`
- 다크 배경(#1A1A1A) 풀스크린. 중앙: 폰 뒷면에 파코니 굿즈를 대는 일러스트 + 동심원 파동 애니메이션.
- 텍스트: "파코니 굿즈를 휴대폰 뒷면에 대주세요".
- 1.5초 후 자동 성공 → 체크 애니메이션 + "태그 완료! 시네마 다이어리로 이동합니다" → `/diary` 자동 이동.
- 데모 편의를 위해 하단에 [태그 시뮬레이션] 텍스트 버튼도 제공(즉시 성공 처리).

### 화면 02 — 시네마 다이어리 홈 `/diary`
- 헤더: 좌측 뒤로가기 + "시네마 다이어리". 흰 배경 — 더보기 화면과 동일한 톤 유지.
- 히어로 카드(GrayCard, `#F4F4F4` radius 16px 플랫): 파코니 캐릭터(레벨별 이미지) + `파코니 Lv.4` + 칭호 + 다음 레벨 진행바 — **더보기의 GradeBar(다크 트랙 + 그라데이션 pill)를 그대로 재사용**, pill에 `Lv.4`, 우측 라벨 `24편`(예: 20/24편).
- 통계 라인: "이번 달 3편 · 올해 24편".
- **PrimaryButton "영화표로 기록하기"** → `/diary/verify`.
- 섹션 "최근 관람 기록": 최근 3건 리스트(포스터 썸네일 48×68 + 제목 + `8/2 (토) 19:20` + `용산아이파크몰 · 5관`) + "전체보기 →" → `/diary/archive`.
- 하단 퀵링크 2개 카드: [장르 취향 뱃지] [마이 무비 다이어리].

### 화면 03 — 영화표 인증 `/diary/verify`
- 헤더: "영화표로 기록". 안내 문구: "기록 방법을 선택하세요".
- 방법 카드 3개 (MenuCell 변형, 아이콘 + 제목 + 설명 + chevron):
  1. **종이 티켓 촬영** — `<input type="file" accept="image/*" capture="environment">`
  2. **모바일 영화표 업로드** — `<input type="file" accept="image/*">` · "이미지에서 인식"
  3. **CGV 예매내역 불러오기** — `가장 간편` 레드 라벨. 탭 시 예매내역 목데이터 3건 바텀시트 → 선택.
  4. 하단 텍스트 링크: "직접 입력하기" (FR-05 수동 경로 → 빈 폼으로 `/diary/verify/result`)
- ①·② 선택 시: 업로드된 이미지 썸네일 + 레드 스캔라인 연출 2초("영화표를 인식하고 있어요...") → `/diary/verify/result`로 자동 기입 상태 전달.
- ③ 선택 시: 스캔 연출 없이 선택한 예매 건으로 즉시 `/diary/verify/result`.

### 화면 04 — 자동 기입 결과 `/diary/verify/result`
- 헤더: "관람 기록 완료".
- 상단 말풍선(파코니 미니 캐릭터): **"자동으로 기입했어! 저장할까? 🍿"** (수동 입력 진입 시: "직접 기록해줘! 🍿")
- 기록 카드(수정 가능 폼):
  - 영화: 드롭다운(목데이터 12편, 검색) — 자동 기입 시 선택된 상태
  - 관람일시: date + time 입력 (`8/2 (토) 19:20` 형식 표기)
  - 극장: 텍스트 (기본 "용산아이파크몰") / 상영관: 텍스트 ("5관") / 좌석: 텍스트 ("H12")
  - 장르: 칩 선택(영화 선택 시 자동 세팅, 수정 가능)
- 자동 기입 연출: 필드가 위에서부터 순차적으로 채워지는 타이핑 애니메이션.
- **PrimaryButton "다이어리에 저장"** → FR-06 판정 → 레벨업이면 `/diary/levelup`, 새 뱃지면 `/diary/badges?new={id}`, 아니면 토스트 "다이어리에 저장했어요 🍿" + `/diary`.

### 화면 05 — 파코니 레벨업 `/diary/levelup`
- 풀스크린 연출: 딤 배경 + confetti.
- 중앙: 파코니 캐릭터 성장 애니메이션, **"파코니 Lv.5 달성! 🎬"**, `Lv.4 → Lv.5` 전환 표기.
- 칭호 리본: **"새 칭호 · 시네마 마니아"** + "24편째 관람".
- 버튼: [씨네톡에 공유] → `/diary/share`, 텍스트 버튼 [다이어리로 돌아가기].

### 화면 06 — 장르 취향 뱃지 `/diary/badges`
- 헤더: "장르 취향 뱃지".
- 섹션 1 "장르별 관람 분포": 수평 바 차트 (장르명 + 편수 + `cgv-red` 바, 최다 장르는 `cgv-gold` 강조).
- 섹션 2 "뱃지 컬렉션": 3열 그리드. 획득 뱃지는 컬러(장르별 아이콘 + 이름 + 획득일), 미획득은 실루엣+자물쇠.
- 쿼리 `?new={id}` 진입 시 해당 뱃지 획득 연출(scale bounce + 광채) 후 그리드 표시.

### 화면 07 — 다이어리 아카이브 `/diary/archive`
- 헤더: "마이 무비 다이어리".
- 상단: **"24 편"** 대형 카운터(Number-Big) + "올해 관람 기록" + 연도 셀렉터.
- 월 필터 칩 (전체 · 1월~12월).
- 포스터 그리드 3열: 각 셀 = 포스터 + 하단 관람일 스탬프. 탭 시 상세 바텀시트(전체 정보 + [기록 삭제] 버튼 — confirm 후 삭제).
- 빈 상태: 파코니 일러스트 + "아직 기록이 없어요. 영화표를 인증해 보세요!" + CTA.

### 화면 08 — 씨네톡 공유 `/diary/share`
- 헤더: "씨네톡 공유".
- 공유 카드 미리보기(캡처 느낌의 카드): 파코니 캐릭터 + "파코니 Lv.5 달성! 24편째 관람 · 시네마 마니아" + 해시태그 `#CGV #파코니 #시네마다이어리`.
- 코멘트 입력(선택).
- **PrimaryButton "씨네톡에 게시"** → 성공 토스트 → 씨네톡 탭으로 이동, 피드 최상단에 내 게시물(♡ 0 · 💬 0)이 추가되어 보임.
- 씨네톡 탭 목업 피드: 목데이터 5건 + 내 게시물. 각 게시물에 `♡ 128 · 💬 21 · ↗ 공유` 카운터(정적).

### 목업 탭 화면 (홈 / 예매·예약 / 매점)
- 실제 기능 없는 정적 화면이지만 **빈 화면 금지** — 첨부 스크린샷과 같은 톤(흰 배경 + 검정 텍스트 + F4F4F4 카드)으로 채운다:
  - 홈: 상단 배너(시네마 다이어리 프로모션 배너 포함 → 탭 시 `/diary`), 무비차트 포스터 가로 스크롤(목데이터 영화 재사용).
  - 예매·예약(중앙 FAB): 영화 리스트 + 비활성 날짜 셀렉터 목업.
  - 매점: 상품 그리드 + **"파코니 NFC 굿즈" 카드** → 탭 시 굿즈 소개 바텀시트 + [태그 시뮬레이션 해보기] → `/nfc`.

## 9. 비기능 요구사항

- **NFR-01 반응성**: 모든 화면 전환·연출은 60fps 유지. Lighthouse Performance 90+ 목표.
- **NFR-02 호환성**: iOS Safari, Android Chrome 최신 2개 버전. 데스크톱 Chrome에서도 480px 컨테이너로 정상 시연.
- **NFR-03 데이터 안전**: localStorage 파싱 실패 시 앱이 죽지 않고 시드 데이터로 복구.
- **NFR-04 접근성**: 터치 타깃 44px 이상, 텍스트 대비 WCAG AA.
- **NFR-05 무결성**: 새로고침·앱 재방문 시에도 기록/레벨/뱃지 상태 유지.

## 12. 완료 기준 (Acceptance Criteria)

1. 앱 접속 시 첫 화면으로 더보기 화면(첨부 스크린샷 재현)이 바로 뜨고, '시네마 다이어리' 탭 1회로 다이어리 홈에 도달한다.
2. 세 가지 인증 방법 모두로 기록 생성 가능하고, 자동 기입 값이 전부 수동 수정 가능하다.
3. 기록 누적으로 레벨업 조건 도달 시 레벨업 연출이 정확히 1회 노출되고, 더보기 프로필 레벨 표기가 갱신된다.
4. 장르 3편 달성 시 해당 뱃지가 잠금 해제되고 획득 연출이 노출된다.
5. 공유 게시 시 씨네톡 피드 최상단에 내 카드가 나타난다.
6. 새로고침 후에도 모든 상태(기록·레벨·뱃지·게시물)가 유지된다.
7. UI가 §7 토큰을 벗어나는 임의 색상·폰트를 사용하지 않는다.
8. 375px 뷰포트에서 가로 스크롤·레이아웃 깨짐이 없다.
9. **더보기 화면을 첨부 스크린샷(`design-reference/more-screen.png`)과 나란히 비교했을 때, '내가 본 영화'→'시네마 다이어리' 텍스트 교체·NEW 표기·아바타 미니 뱃지·하단 배너 교체 외에는 차이가 없다.**
